# 미션 - 크리스마스 프로모션

## 12월 이벤트 플래너

<Input>
1. 방문날짜
    예외상항)
        숫자 외 입력
        1~31 범위밖 숫자
2. 메뉴
    예외상황)
        메뉴 외 입력
        갯수 : 1 이상 숫자
        잘못된 형식
        중복 메뉴
        음료만 주문 
        20개 넘게 주문

<Output>
1-1. 주문 메뉴 (메뉴)
    메뉴를 그대로 받아와 형식에 맞게 재출력
1-2. 할인전 총주문 금액
    메뉴 가격 총합 계산
1-3. 증정메뉴
    할인전 총주문 금액 >= 120,000원 일 경우, 샴페인 1개 증정
    아닌 경우, 없음
2-1. 혜택내역 (방문날짜)
    방문날짜에 따라 계산
    - 크리스마스 디데이 할인
        1000원 + (날짜-1) * 100원 만큼 할인
    - 평일/주말 할인
        개당 2,023원 할인
        주말 할인 - 금,토 (7로 나눠서 나머지 1,2) - 메인 메뉴 
        평일 할인 - 일~목 - 디저트
    - 특별 할인
        일괄 1000원 할인
        매주 일요일 (7로 나눠서 나머지 3) + 25일
    - 증정 이벤트
        증정메뉴 받을 경우, 25,000원 할인
2-2. 총 혜택 금액
    혜택내역 총합 계산
2-3. 이벤트 배지
    총 혜택 금액 기준 선정
        >= 20,000원 산타
        >= 10,000원 트리
        >= 5,000원 별
        그외인 경우, 없음
2-4. 할인후 예상 결제 금액
    =(할인전 총주문 금액 - 총 혜택 금액)


#### 메뉴

```
<애피타이저>
양송이수프(6,000), 타파스(5,500), 시저샐러드(8,000)

<메인>
티본스테이크(55,000), 바비큐립(54,000), 해산물파스타(35,000), 크리스마스파스타(25,000)

<디저트>
초코케이크(15,000), 아이스크림(5,000)

<음료>
제로콜라(3,000), 레드와인(60,000), 샴페인(25,000)
